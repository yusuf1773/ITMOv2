## Context Pack для первого рабочего сценария

### Факты и правила

- Задача помощника: по одному PR из diff вернуть 1) краткое описание изменения, 2) не больше трёх рисков с `file`, `line`, `evidence`, `risk`, 3) список проверок, которые стоит запустить. Решение принимает человек. | CASE.md «Задача помощника»
- SEC-1: перед отправкой во внешний LLM из diff удаляются токены, пароли и приватные ключи. | CASE.md «Правила репозитория»
- API-1: diff длиннее 20 000 символов отклоняется с HTTP 413. | CASE.md
- REL-1: внешний LLM-вызов имеет timeout 10 секунд; ошибка превращается в контролируемый ответ. | CASE.md
- OUT-1: ответ содержит `summary`, массив `risks` (макс. 3) и массив `checks`. В `risks` поля: `file`, `line`, `evidence`, `risk`. | CASE.md
- SCOPE-1: сервис только советует; он не пишет код и не выполняет действия в GitHub. | CASE.md
- QA-1: риск включается в ответ, только если он подтверждён строкой diff или правилом репозитория. | CASE.md
- OBS-1: в лог пишутся только `request_id`, длительность и статус; содержимое diff и ответа модели не логируется. | CASE.md

### Формат входа и результата

- Вход: HTTP `POST /api/reviews` с JSON-телом вида `{ "diff": "<git diff>" }`. | TRAINING_PR.diff (app/api.py:35–38)
- Результат: JSON с полями `summary: str`, `risks: list[Risk] (<=3)`, `checks: list[str]`. | CASE.md (OUT-1)

### Ограничения и запрещённые действия

- Запрещено: approve/merge PR, менять код, выполнять действия в GitHub; передавать секреты в LLM; логировать содержимое diff/ответа. | CASE.md (SCOPE-1, SEC-1, OBS-1)
- Ограничения: длина diff <= 20 000 символов (иначе 413); timeout LLM-вызова 10 секунд, ошибки — в контролируемый ответ. | CASE.md (API-1, REL-1)

### Хороший пример

`app/review_service.py:16 — diff отправляется во внешний LLM без удаления секретов, что нарушает SEC-1. Проверка: передать diff с тестовым token и убедиться, что в prompt осталось [REDACTED].` | CASE.md «Примеры комментария»

### Плохой пример

`Код можно улучшить. Добавьте тесты и обработку ошибок.` | CASE.md «Примеры комментария»
