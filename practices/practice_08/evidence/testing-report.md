## Как запустить

Перейдите в папку `practice_08`. Нужны Node.js 22 или новее и Google Chrome для браузерных проверок.

```bash
npx pnpm@11.25.0 install --frozen-lockfile
npm run test:all
npm run test:e2e:report
```

`pnpm` не должен быть заранее установлен глобально: первую команду запускает `npx`. Если зависимости уже установлены, первую команду можно пропустить. `npm run test:all` запускает сначала 10 тестов Vitest, затем 4 теста Playwright. Браузерные тесты сами запускают и останавливают локальный сайт; отдельный `npm run dev` им не нужен.

Последняя команда запускает сервер отчёта и печатает локальный адрес. Откройте этот адрес в браузере, выберите один из четырёх тестов и прокрутите до раздела **Screenshots**. Пока смотрите отчёт, оставьте терминал с этой командой открытым. Для остановки нажмите `Ctrl+C`.

Если нужны отдельные запуски:

```bash
npm run test:run          # только 10 тестов Vitest
npm run test:e2e          # только 4 теста Playwright и новый HTML-отчёт
npm run test:e2e:report   # открыть последний HTML-отчёт
```

Для проверки сборки отдельно выполните `npm run build`. Готовые файлы появятся в `dist/`.
