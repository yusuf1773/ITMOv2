# Проверка через Playwright MCP

Дата: 21 ноября 2026 года. Использован официальный сервер Microsoft `@playwright/mcp` версии 0.0.86 и установленный Google Chrome. Проверка запускалась через инструменты MCP (`browser_navigate`, `browser_resize`, `browser_run_code_unsafe`, `browser_take_screenshot`, `browser_console_messages`).

## Проверенные действия и результат

- На ширине 390 px не было горизонтальной прокрутки.
- До прохождения первого урока открывался экран «Пока нечего повторять».
- В первом уроке открывались два слова, правило и три упражнения.
- Пустой выбор и пустой перевод вызывали понятные сообщения; неправильный ответ показывал объяснение.
- Перевод, введённый заглавными буквами и подтверждённый Enter, засчитывался.
- После завершения урока появлялось «Прогресс сохранён»; после обновления страницы оставалось «Пройдено 1 из 3 уроков».
- В плановом повторении ошибочный элемент возвращался один раз в конец сессии; после сохранения открывалась свободная тренировка.
- Клавиша Tab переводила фокус на элементы управления, видимый фокус появлялся; Enter запускал урок.
- При искусственном отказе `localStorage.setItem` результат оставался на экране, переход к курсу блокировался. После восстановления записи кнопка «Повторить сейчас» сохраняла тот же результат и открывала следующий урок. [Снимок ошибки](playwright-mcp-save-error.png).
- В проверенных сценариях Playwright MCP сообщил 0 ошибок и 0 предупреждений консоли.

Ошибку записи создали специально для проверки поведения. Первоначальный прогон проверки клавиатуры остановился из-за сохранённого прогресса предыдущего прогона: вместо «Начать урок» была кнопка «Пройти ещё раз». После очистки прогресса проверка прошла. Код приложения менять не потребовалось.

Сервер MCP подключён к пользовательской конфигурации Codex. В текущем чате новые инструменты не появились автоматически, поэтому сервер вызван отдельным MCP-клиентом. Клиентский сценарий запускался из временной папки и не является частью постоянного набора тестов проекта.

## Как связаны MCP и автоматические тесты

MCP-проверка выше запускалась отдельно. Постоянные наборы тестов проекта: 10 проверок Vitest и 4 браузерные проверки Playwright Test. Команды запуска и общий результат приведены в [отчёте о тестировании](testing-report.md). HTML-отчёт Playwright Test содержит только 4 браузерные проверки и их скриншоты.
